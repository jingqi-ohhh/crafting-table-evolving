# crafting-table-evolving
Adds more crafting tables with chest-like storage.

## introduction
This mod adds crafting tables made from additional wood types, wall-mounted crafting tables, and a portable crafting table. Crafting tables placed in the world also have chest-like storage. By default, hold Left Alt and right-click a crafting table to open the storage. This can be changed in Key Binds

## notice
Before Minecraft 1.21.2 version，if you want crafting portable crafting table have to turn on bundles of experiments or install mod about bundle.
